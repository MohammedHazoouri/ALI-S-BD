# The Ali Issue — birthday website

A responsive, three-part birthday tribute built with plain HTML, CSS and JavaScript. No build tools or install steps required.

## Run it

1. Unzip the folder.
2. Open `index.html` in a modern browser. (For the most reliable local image behavior, serve the folder with any static file server.)

## Make it personal

- **Write your own message:** the starter note is in friendly Levantine Arabic. Open `script.js` and edit the three paragraphs in `LETTER_TEXT` to make it sound like you; Arabic text is supported.
- **Add Ali's real photos:** replace the four files in `assets/` while keeping these filenames: `ali-core.png`, `ali-being-ali.png`, `friends.png`, `ali-bac.png`. The current illustrations are original concept visuals, not photos of Ali.
- The hero birthday copy, labels, navigation, gallery captions and Arabic notes live in `index.html`.

## Contents

- `index.html` — semantic page structure and all three sections.
- `styles.css` — responsive art-editorial styling, motion, and reduced-motion support.
- `script.js` — reveal-on-scroll, progress line, accessible gallery lightbox, and birthday confetti.
- `assets/` — four original gallery images.

The page uses a Google Fonts stylesheet when online and sensible system fallbacks when offline.
